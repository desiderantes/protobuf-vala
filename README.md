# protobuf-vala

Vala support for Protocol Buffers (proto2 and proto3).

## Requirements

- Vala compiler (`valac >= 0.56`)
- Meson (`>= 1.10.0`) and Ninja
- GLib 2.0 (`>= 2.80`)
- `gee-0.8` (required for proto3 `map<K, V>` fields)
- `libprotobuf-c` and `protoc`
- (Optional) valapoet (https://github.com/desiderantes/valapoet). This is already included as a meson subproject.

> [!NOTE]
> Code generated by `protoc-gen-vala` requires GLib 2.80+.

> [!WARNING]
> Proto3 map support (`map<K, V>`) generates code utilizing `Gee.HashMap<K, V>`. Consequently, projects compiling generated Proto3 map files must link against `gee-0.8`. 

## Building

```bash
meson setup build
ninja -C build
```

## Running Tests

```bash
meson test -C build
```

## Usage

Compile `.proto` files using the `protoc-gen-vala` plugin:

```bash
protoc --plugin=build/src/protoc-gen-vala --vala_out=src my_file.proto
```
